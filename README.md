# Music Store Database SQL Project

This project implements a music store database using SQL. It includes the database schema, data population scripts, and advanced SQL queries for data analysis.  The project demonstrates the use of various SQL features such as joins, window functions, aggregate functions, and Common Table Expressions (CTEs).

## Features

* **Database Schema:**  `Music Store Database Schema.sql` contains the SQL script to create the database and all the necessary tables.
* **Data Population:** `data population script.sql` contains the scripts to populate the tables with sample data.
* **Analysis Queries:** `Queries for analysis on Music Store DB.sql` contains a series of analytical queries demonstrating the use of advanced SQL features. These queries cover various analytical tasks, including:
    * Joining tables to retrieve related data.
    * Using window functions for calculations across partitions of data.
    * Employing aggregate functions to summarize data.
    * Utilizing CTEs to simplify complex queries.

## Getting Started

To run this project, follow these steps:

1. **Database Setup:** Execute the `Music Store Database Schema.sql` script against your SQL server. This will create the `Music Store` database and all the required tables.  You can use any SQL client (e.g., SQL Server Management Studio, MySQL Workbench, pgAdmin) to do this.

2. **Data Population:** Execute the `data population script.sql` script. This will populate the tables with sample data.

3. **Running Analysis Queries:** Open the `Queries for analysis on Music Store DB.sql` file in your SQL client.  You can then execute each query individually to see the results of the analysis.

## Technologies Used

* SQL (e.g., MySQL, PostgreSQL, SQL Server - the specific database system is up to you, just make sure the scripts are compatible)
